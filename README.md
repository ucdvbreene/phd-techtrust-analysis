# PhD TechTrust Analysis

## Overview
This repository contains analysis for Technology Trust in AI-assisted credit assessment.

## Folder structure
- data/raw/ - Original Excel dataset
- notebooks/ - Jupyter notebooks for analysis
- results/ - Figures, tables, and output files
- docs/ - Methodology notes, supplementary materials

## Usage
1. Open the notebooks in the `notebooks/` folder.
2. Processed results or plots can be saved in `results/`.
